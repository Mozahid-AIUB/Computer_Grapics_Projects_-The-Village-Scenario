# Computer Graphics Project - The Village Scenario

A computer graphics project depicting a village scenario with various visual elements and animations.

## Overview
This project showcases computer graphics techniques by creating a realistic or stylized village scene with multiple objects, lighting, textures, and animations.

## Features
- 3D village landscape
- Building structures
- Character models
- Lighting and shading
- Animations and interactions
- Environmental effects

## Technologies
- Graphics API: OpenGL/DirectX
- Programming Language: C/C++
- Additional Libraries: GLFW, GLEW, GLM

## How to Run
```bash
g++ -o village *.cpp -lGL -lGLFW
./village
```

## Controls
- Arrow keys for navigation
- Mouse for camera control
- Special keys for interactions
